### Current RL Implementation and Limitations

- Current setup trains on a single voxel rather than the full phantom
- The agent converges quickly with low percentage error because the single-voxel problem is too simple
- Already implemented randomization of T1 and T2 values within a specified range for each RL step to prevent the agent from memorizing values

### Technical Implementation Details

- Voxelization approach: configurable voxels per millimeter square
- Each sphere defined by radius with voxelized grid function that places voxels at specified x, y, z steps
- Voxel density is adjustable - allows rough voxelization during RL training and higher accuracy for evaluation
- One spin per voxel in the grid
- Trade-off exists between voxel density (accuracy) and execution time

### Recommendations for Improvement

- **Adding variance to prevent overfitting**: Consider implementing phantom rotation or other variance since the algorithm shouldn't know the phantom's exact position in advance
- **T1/T2 randomization**: Using minimum and maximum values from the phantom to choose random values in between is appropriate
- **Adding noise to output data**: Essential for realistic simulations
    - Add Gaussian noise on both real and imaginary channels of the complex signal
    - Same standard deviation for both channels
    - Independent noise for each sample but from the same distribution
    - Noise level affects problem difficulty - more noise makes the problem harder
    - Noise may not be necessary during training but is definitely needed for evaluation
