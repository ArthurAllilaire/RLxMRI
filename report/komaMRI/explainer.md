
In the KomaMRI simulations used later in this thesis, the gyromagnetic
ratio is represented in cycles per second per tesla:
$\gamma = 42.577\times10^6\ \text{Hz}\ \text{T}^{-1}$. Thus gradient
areas are converted to k-space using $\mathbf{k}(t) =
\gamma\int_0^t\mathbf{G}(\tau)\,d\tau$ with $\gamma$ in Hz/T, rather
than using the angular-frequency value $2\pi\gamma$.
